# E-242-01: Subagent vocabulary in plan + implement skills

## Epic
[E-242: Align Dispatch/Plan/Implement Workflow to Subagent Framing](../E-242-align-dispatch-to-subagents/epic.md)

## Status
`DONE`

## Description
After this story is complete, the plan and implement skills instruct agents to spawn named subagents via the `Agent` tool with implicit team formation and automatic teardown, instead of calling the removed `TeamCreate` / `TeamDelete` tools. The dispatch and planning behavior is unchanged — only the vocabulary and the two dead tool calls are removed.

## Context
`.claude/skills/plan/SKILL.md` and `.claude/skills/implement/SKILL.md` are the two skills that drive team formation. They currently tell the main session to "Create the team" via `TeamCreate` and to "delete team" at teardown. Both tools were removed in Claude Code v2.1.178. This story aligns those skills to the canonical glossary (Technical Notes TN-1) while preserving every behavioral element (TN-2): the explicit `shutdown_request` to PM stays, the staging boundary stays, the closure sequence stays, and the resumability-dependent handoffs (unified-team-lifecycle, PM context-recovery) stay with vocabulary aligned only.
