# E-260-01: Remove the verbatim-relay mandate apparatus

## Epic
[E-260: Dispatch Cost Accounting](../E-260-dispatch-cost-accounting/epic.md)

## Status
`DONE`

## Description
After this story is complete, the context layer no longer carries the standing instructions that mandate verbatim relay of findings and context between live agents, nor the "binds every agent on every session" framing that generalized them. The three source files (`implement/SKILL.md`, `dispatch-pattern.md`, `tool-output-integrity.md`) retain their genuinely load-bearing content (the full-story-file spawn mandate, concurrency-under-load advice, the failure taxonomy and response protocol) but lose the apparatus that requires expensive relay. This story also corrects one closure-sequence diff command (an operator-authored fix to an existing mechanic) so a parked epic's closure cannot revert later-landed work.

## Context
This is the epic's central deletion (Scope: "Remove the standing instructions that require expensive relay"). The E-256 dispatch produced ~640k characters of agent-to-agent prose; the `never summarize` / verbatim-relay mandate is what required it. These deletions must come before the counter and ratchet are added (epic Background: "The instructions have to go first"), so this story is the root of the deletion chain and 02 depends on it (shared file, disjoint regions).

The exact edits are enumerated in Technical Approach. This is a deletion-first story under the epic's Operating Rule: the verbatim removed text is snapshotted to a durable location BEFORE any edit. The closure-diff correction (AC-6) is a bugfix to an existing command, not a deletion, so it is not subject to the snapshot rule.
