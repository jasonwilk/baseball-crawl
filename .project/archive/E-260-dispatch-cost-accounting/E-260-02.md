## Technical Approach
The true behavior (from the proven memory file): the project's `tests/__init__.py` causes pytest to prepend the repo root to `sys.path[0]`, which shadows the editable-install meta path finder — so pytest run from the worktree imports the WORKTREE's `src/`, not main's. The correct framing for the per-story ban is therefore: a per-story worktree run tests only that worktree's partial, unmerged state (not yet the closure tree), so it is not the authoritative signal; the one authoritative full-suite run is the Phase 5 Step 1b closure gate against the merged main checkout.

Note the six enumerated sites are five distinct constraint *statements* plus one cross-ref (`code-reviewer.md` carries two — the block and its `:62` cross-ref). Correct each in place. Minimal edits — do not restructure surrounding prose beyond what the factual fix requires. Re-locate line numbers after E-260-01's `implement/SKILL.md` deletions.
