## Description
After this story is complete, `.claude/agents/code-reviewer.md` will carry the nine rubric edits from the agentic-flow review (targeting structural gap classes 1/3/4/7/8/9), a new AC×surface matrix rubric item (class 6), and machine-findable delimiter pairs wrapping both the Bug Pattern Checklist and the Priority-4 Security checklist so a downstream story can extract them at prompt-assembly time. ## Context
Cross-cutting integration/mirror-path drift is the largest CR-missed defect class (66 findings) and is a review-*scope* problem the E-251 routing fix cannot touch; concurrency and security have only ever been caught by Codex because CR has no rubric for them. This story adds the rubric CR needs to catch those classes itself. Two of the nine edits are edit-in-place REVERSALS of current guidance (not additions) — they must remove the old text as well as add the new. The delimiter markers this story installs are the structural precondition for E-258-03 (single-sourcing the Codex rubric off this file). All rubric content and the delimiter contract are specified in the epic's Technical Notes TN-5 and TN-1.
