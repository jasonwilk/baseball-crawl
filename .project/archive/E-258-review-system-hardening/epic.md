## Overview
The 2026-07-07 agentic-flow review found the reviewer stack catches reviewer-*quality* defects well but structurally leaks whole classes of *structural* defect: cross-cutting integration/mirror-path drift (the largest CR-missed class, a review-*scope* gap the E-251 routing fix cannot touch), context-layer doc drift (findings that reach Codex with zero prior review), concurrency and security (only ever caught by Codex, with no CR rubric), and a plain "implement E-NNN" — the user's documented default — that closes with NO combined-diff reviewer at all. This epic hardens the review system against those classes: it adds the missing rubric edits to the code-reviewer, restructures the implement skill so a combined-diff CR review runs unconditionally at closure and Codex adjudicates *before* CR (ending the approve-then-reverse loop), gives context-layer epics a real review discipline, single-sources the Codex rubric off CR's checklist so the two reviewers stop drifting, hardens the codex-review tooling against a fabrication hole, and installs a deferred process check to re-measure whether the remaining rubric spend is earning its keep. Everything here is context-layer work.

### TN-2: Item-2 codex-review tooling hardening (E-258-03)
- **Deterministic result file**: `scripts/codex-review.sh` computes a `RESULT_FILE` (claude-architect's design: `/tmp/codex-review-$(date +%s).txt`, chosen to avoid any git/worktree interaction), tees the Codex output to it (stdout still streams; the script's `set -o pipefail` already propagates the exit code), and emits a receipt to stdout: `RESULT_FILE=<path>`, `wc -l` of the file, and `tail -n1`. `codex-review/SKILL.md` Step 4's read-receipt gate consumes this deterministic file instead of instructing a manual `> file` redirect (44/48 invocations skipped the manual redirect; 2 fabrication incidents resulted). **Tee-placement precision** (per CR-N2): the tee goes on the codex pipe itself (`codex exec … - | tee "$RESULT_FILE"`); with `set -euo pipefail` the rightmost-non-zero rule means codex's non-zero exit still propagates through the zero-exit `tee`, so exit-code preservation holds. All THREE mode branches (`uncommitted`/`base`/`commit`, script lines ~199/212/225) need the tee — "when a review runs" covers all three.
- **ACMR default on the WORKDIR diff**: the WORKDIR (epic-worktree) uncommitted diff defaults to `--diff-filter=ACMR` (added/copied/modified/renamed), so pure deletions do not burn Codex's 20-minute budget and degrade it to static-only on the largest epics (E-239's 2.57M-char diff). Scope: the WORKDIR path only, not the standalone staged/unstaged path.
- **Consistency rewrite**: `codex-review/SKILL.md` currently states at ~line 243 "do NOT change the script's default `git diff main`, which keeps deletion signal for normal reviews." Item 2 REVERSES that for the WORKDIR default, so E-258-03 MUST rewrite that note (and any co-located anti-pattern language) so the skill does not self-contradict.
- Note in the skill that Codex's pytest sweep is best-effort; the authoritative test gate remains Phase 5 Step 1b.
