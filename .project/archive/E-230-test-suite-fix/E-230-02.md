## Description
After this story is complete, the two spray-chart geometry tests assert the **current, confirmed-intended** square `(3,3)` cropped output of `src/charts/spray.py`. The user confirmed this is the desired print output (see Context), so the resolution is a **test-fix only** — `src/charts/spray.py` is not modified. The stale assertions (pre-crop portrait layout) are updated and the now-misleading "3x4" test names are renamed.

## Context
This is Cluster 2 from discovery (2 failures, deterministic — 3/3 reproductions, not flaky): `tests/test_charts/test_spray.py::test_render_uses_3x4_figsize` (assertion at `tests/test_charts/test_spray.py:198-204`) and `::test_render_png_dimensions_approx_3x4_at_150dpi` (assertions at `:362-375`; the `height > width` portrait check at `:375` is the actual failing line). Commit `a8d6ac6` ("redesign scouting report print layout") deliberately changed `src/charts/spray.py` to `figsize=(3,3)` (line 451), cropped the axes (`set_ylim(365, 8)` / `set_xlim(-4, 324)`, lines 479-480), at `dpi=150` with `bbox_inches="tight"` (line 494) — producing the current near-square output — but left these two pre-crop portrait-layout assertions untouched. The "3x4" in both the commit message and the test names refers to the **page card grid** (12 cards/page), NOT the figure aspect ratio; the figure itself is intentionally square.

**Design intent is settled by ground truth** (no precondition remains): the user confirmed the desired output is the live production report `https://bbstats.ai/reports/zoVS7ElENReB4Kkr`, which renders near-square spray charts — exactly what the current code produces. Combined with the deliberate redesign commit `a8d6ac6`, this resolves the former Open Question to **square is intended → fix the tests**. The story is unconditionally dispatchable as a test-fix; there is no code-fix branch.
