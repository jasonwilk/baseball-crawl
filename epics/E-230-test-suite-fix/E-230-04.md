## Description
After this story is complete, the dispatch workflow makes "a closed epic has a green test suite" a hard, **executable** invariant — not inert policy text. A new unconditional Phase 5 closure step runs the full `pytest` suite in the main checkout before the PM marks the epic COMPLETED; reds route into the existing remediation loop until green. Supporting context-layer edits document the gate, scope the per-story pytest ban so it does not contradict the closure pass, reconcile the adjacent Phase 5 prose the new step makes false, and add the inverse-direction Test-Validates-Spec guidance. Footprint ~15-18 lines across 4 files. No new hook, CI, or rule file; no reintroduction of the E-229-removed pytest-verbose/exitfirst machinery.

## Context
This is the prevention bucket the user chose to add as a story in E-230. It is context-layer work; per routing precedence, any context-layer path forces claude-architect — this story is claude-architect's, and the design below is claude-architect's (it consulted first-hand on the dispatch path).

The **crux** (Codex P1): the original 3-file edit was inert. The live dispatch path never runs the full suite — `.claude/skills/implement/SKILL.md:244` skips code-reviewer for context-layer-only stories, `:254` tells CR "do NOT run pytest — verify by inspection," and Phase 5 closure has no full-suite step. So a "CR runs the full suite" trigger in `code-reviewer.md` would never fire. The fix wires the gate into the **executable** closure sequence, anchored to the existing Phase 5 **Step 1a** precedent (which already spawns code-reviewer for a closure-time invariant audit in the main checkout).

**Boundary reconciliation** (why CR-runs-pytest-at-closure is not a contradiction): the per-story "no pytest" ban exists because worktree pytest tests *main's* code (the editable-install meta-path-finder hardcodes main's `src/`), so per-story worktree pytest is misleading. At **closure** the changes are staged/patched into main, where pytest IS authoritative. The ban is therefore scoped to per-story worktree review, and the closure-time full-suite pass is a named exception — a real reconciliation, not a loophole.

claude-architect owns the exact wording/placement of all 4 edits (domain-expert-designs); the ACs below specify outcomes.
