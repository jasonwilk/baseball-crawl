## Description

entry for the `resolve_unlinked()` follow→bridge→unfollow path, cross-referenced from the
central quarantine rule. This is the highest-priority quarantine item because the path mutates

## Context
`resolve_unlinked()` (`src/gamechanger/crawlers/opponent_resolver.py`) and its worker
`_follow_bridge_unfollow()` POST `/teams/{root_team_id}/follow` — mutating external GC state
against `root_team_id`, which is the WRONG namespace (it is not `gc_uuid`). The function's own
docstring says it is unverified. Banning it has two halves: the in-code banner (story 04) and
this durable context-layer entry. CA recommended keeping this as its own story (separate from
the central rule) because it is the highest-priority ban and lands in a distinct, frequently-
consulted file (`gc-uuid-bridge.md`).
