## Description
After this story is complete, `.claude/skills/implement/SKILL.md` will run a combined-diff CR integration review on EVERY dispatch (not only "and review"), with Codex — when present — running before that CR pass so CR adjudicates a real finding list instead of approving-then-reversing; it will carry a mechanical Invariant-Audit trigger checklist (every trigger evaluable from permitted artifacts) and a one-line AC×surface pointer. A new `.claude/rules/doc-sweep.md` glob-triggered rule will require semantic (not token-grep-only) doc review for context-layer/doc files. (The dormant-migration review rubric was re-homed to E-258-01 per Codex P2 / architect C-3 — it is review guidance, so it belongs in `code-reviewer.md`.) This is the workflow-side half of the review-system hardening.

## Context
Today a plain "implement E-NNN" — the user's documented default — closes with NO combined-diff reviewer at all; both Phase 4a (CR integration) and Phase 4b (Codex) are gated on the "and review" modifier. And when both run, CR reviews first and then reverses itself after Codex finds issues (E-239, E-251, E-253). This story fixes both: it makes the CR integration review unconditional and reorders so Codex precedes it. Separately, context-layer stories skip per-story CR by design and token-grep doc verification structurally misses prose (E-250's "across games and seasons" survived a keyword sweep) — the new doc-sweep rule closes that. The target Phase 4/5 structure, the load-bearing invariants, the hard constraint on the full-suite gate, and the doc-sweep rule's shape are all specified in epic Technical Notes TN-3 and TN-4.
