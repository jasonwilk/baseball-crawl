## Overview
The E-267 independent audit's process verdict: the epic failed not for lack of checks but from too many SAME-CONTEXT checks manufacturing false confidence — 16+ internal review rounds (12 story-rounds + 4 Codex spec + 1 Codex code) all missed a live irreversible-data-loss defect, while the one INDEPENDENT no-continuity review caught it in a single pass. This epic is a NET-DELETION-plus-targeted-additions redesign of the process layer: drop/soften the machinery that manufactures false confidence (a hard send-cap, a redundant Codex round, an orchestrator told to adjudicate code it cannot read), and add the one thing that actually worked — an independent no-continuity review for destructive-path epics — plus a decide-first Autonomy Gate, a mechanical annotation-as-coverage check, and a verbatim Closure Evidence schema. Every change cites its defect (P-1..P-10 in `.project/research/E-271-e267-audit-findings.md`); the meta-layer is otherwise FROZEN.

## Background & Context
The consolidated audit findings (`.project/research/E-271-e267-audit-findings.md`) record ten process findings (P-1..P-10). The headline (P-1): shared context ⇒ shared blind spot — every internal review layer inherited the ACs and the stories' "unreachable in production" annotations, so the same false premise rode through all of them; the Fable audit, given the goal but not the rationale, falsified it. Critically, the sharpening round established that NO review layer was pure ceremony (Codex spec rounds caught genuine pre-code issues; story-04's circuit breaker caught a defect in the reviewer's own proposed fix) — the failure was false-confidence ACCUMULATION, not zero value. So this redesign targets redundancy and continuity-reliance, not review value: it caps a round, it does not eliminate review; it REPLACES (not supplements) the same-context closure review for destructive epics. claude-architect is the design owner (context-layer domain); this epic implements its design (below), with PM framing ACs and owning scope/sequencing.
